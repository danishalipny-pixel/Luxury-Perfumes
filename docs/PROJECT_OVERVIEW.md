# Project Overview — NOIRÉLLE

## Brand Vision & Purpose
NOIRÉLLE is an ultra-luxury fragrance e-commerce web platform engineered to reflect the timeless elegance, depth, and sophistication of haute perfumery. Designed from the ground up for a discerning international audience, the application synthesizes high-performance modern web technologies with an editorial visual identity.

## Design Philosophy
The digital storefront departs from generic e-commerce templates by treating each collection as an evocative sensory world:
- **Unique Atmospheric Color Palettes:** Over 20 distinct page backgrounds (Champagne Ivory, Midnight Charcoal, Dusty Rose, Muted Sage, Deep Espresso, and Warm Stone) create individual environments while maintaining coherent typographic and architectural identity.
- **Flacon Presentation Standards:** Product bottle imagery is strictly framed with container constraints (`object-fit: contain`) to preserve bottle geometries, atomizers, and handcrafted caps, while atmospheric campaign headers leverage panoramic cinematic layouts (`object-fit: cover`).
- **Typography:** Classical serif typography (Cormorant Garamond, Playfair Display) paired with clean geometric body types (Inter, Manrope) creates refined visual hierarchy.

## Key Modules & Core Architecture
1. **Catalog & Discovery:** Multi-tiered fragrance family taxonomies (Woody, Floral, Oriental, Fresh, Amber, Citrus) with real-time client-side search, filtering, and multi-parameter sorting.
2. **Interactive Flacon Displays:** Multi-angle image carousels with smooth hover transitions from full-bottle presentation to macro craftsmanship close-ups.
3. **Cart & Wishlist Contexts:** Persistent client-side state synchronized across tabs via browser LocalStorage with animated drawer drawers and notifications.
4. **Checkout & Concierge Ordering:** Full end-to-end checkout interface paired with a WhatsApp order routing engine that generates structured order manifests for personalized client interactions.
5. **Administrative Showcase:** Dedicated administration dashboard interface for inventory overview, catalog inspection, and order monitoring.
